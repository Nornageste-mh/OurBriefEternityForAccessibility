# 安装说明（《永恒与星辰与日常》读屏无障碍补丁）

> 发布包内文档。面向**已在 Steam 购买《永恒与星辰与日常》的玩家**
> （AppID **4169820**，游戏版本 **1.63**，引擎 Ren'Py 8.6.0）。
>
> 这一份讲**安装 / 卸载 / 按键 / 朗读行为**；遇到问题先翻同目录的
> [`常见问题.md`](常见问题.md)。

## 这是什么

给《永恒与星辰与日常》加的**读屏无障碍层**：让 NVDA 这类屏幕阅读器
能读出剧情文本、选项、菜单与界面控件，盲人玩家可以自己走完一遍。

- **不是官方补丁。** 与游戏的开发商、发行商没有任何关系，也没有得到授权或背书。
- **只支持 Windows**，读屏后端支持 **NVDA**；不用读屏软件也能出声
  （补丁可以用引擎同款 SAPI 兜底）。**争渡读屏（ZDSR）不支持**，见常见问题。
- 补丁形态：往游戏目录放若干 `.rpy` 脚本，**不修改任何游戏原有文件**、
  **不重新打包 `.rpa`**、**不改动画面**（尺寸 / 位置 / 颜色 / 字体 / 过渡 / 音效都不动）。
- 发布包与仓库**不含任何游戏资源**：没有解包产物、没有反编译脚本、
  没有剧本原文、没有图片或音频。
- 解锁条件与正常游玩完全一致：补丁**不扩大可达范围**（未解锁的按钮只朗读
  「尚未解锁」，不会变成可点），也**不提供「跳过剧情」的替代通道**。

**请通过 Steam 购买正版后再使用本补丁。**

## 装之前

- Windows 10 / 11
- 游戏已装好、能正常启动（Steam 版）
- **关掉游戏**再装
- 一个能出声的朗读后端：装了 NVDA 就用 NVDA；没装也能用系统自带的中文语音
  （SAPI，需要系统里装了中文语音包：设置 → 时间和语言 → 语音）
- 游戏装在含中文的路径下**没关系** —— Steam 默认的
  `…\steamapps\common\永恒与星辰与日常` 就是中文目录名，本补丁实测可用

## 安装（解压即用）

**本发布包没有安装器** —— 不需要运行任何脚本，也不需要打开 PowerShell。
把 zip 解压到游戏目录、合并覆盖，就装完了。

1. 从发布页下载 `OurBriefEternityA11y-<版本>.zip`
   （<https://github.com/Nornageste-mh/OurBriefEternityForAccessibility/releases>）。
2. 找到**游戏根目录**：Steam 库里右键《永恒与星辰与日常》→ 管理 → 浏览本地文件，
   打开的就是它 —— 那一层里应当同时有 `OurBriefEternity.exe` 与 `game\` 子目录。
3. 把 zip **解压到游戏根目录**。系统问「是否合并 / 替换同名文件」时选**合并 / 覆盖**。
4. 从 **Steam** 启动游戏。**不用手动启动任何别的东西。**

zip 里的目录结构与游戏目录**一一对应**，解压完就到位了 —— 这就是「解压即用」的全部机关：

| zip 里的路径 | 解压后落到 |
|---|---|
| `game\a11y_platform\*.rpy` | `<游戏目录>\game\a11y_platform\` |
| `game\a11y_game\*.rpy` | `<游戏目录>\game\a11y_game\` |
| `game\nvdaControllerClient64.dll` | `<游戏目录>\game\` |
| `安装说明.md`、`常见问题.md`、`licenses\` | `<游戏目录>\`（纯文本，留着不影响运行，删掉也行） |

### 解压后游戏目录里多了什么（只有这三处）

| # | 多了什么 | 位置 |
|---|---|---|
| 1 | 补丁自己的 `.rpy`（当前 **11 个**） | `<游戏目录>\game\a11y_platform\`（6 个）、`<游戏目录>\game\a11y_game\`（5 个） |
| 2 | 第三方朗读库 `nvdaControllerClient64.dll`（NVDA 官方提供，LGPL-2.1，**未经修改**） | `<游戏目录>\game\` |
| 3 | 两份说明文档与第三方许可证文本 | `<游戏目录>\`、`<游戏目录>\licenses\` |

**游戏原有的文件一个都没被改、也没被替换** —— 补丁只往 `game\` 下新增它自己那两个目录。

> 关于那个 DLL：本作的游戏目录里**本来就带**同名文件，补丁按
> `<游戏目录>\game\a11y_platform\` → `<游戏目录>\` → `<游戏目录>\game\`
> 的次序找它，**实际加载了哪一份会写进 `log.txt`**。包里的这份是兜底
> （换到没有自带该 DLL 的作品上也能复用同一套平台层），覆盖或删掉都不影响本作。

### 怎么确认装上了

从 Steam 启动游戏，进主菜单后应当听到这一句（`X.Y.Z.W` 随版本变化，
下面这句是 **0.0.0.9** 的样子）：

> 「永恒与星辰与日常无障碍补丁 0.0.0.9 已加载。朗读后端：NVDA。」

- **听到了** ⇒ 补丁在跑。后面听不到东西，按 [`常见问题.md`](常见问题.md) 从第 1 条往下查。
- **没听到** ⇒ 先确认 `<游戏目录>\game\` 下真有 `a11y_platform\` 与 `a11y_game\`
  两个目录，并且**是从 Steam 启动的**（直接双击游戏目录里的 `OurBriefEternity.py`
  会撞上游戏自己的报错，那不是补丁的问题）。

### 升级（之前装过旧版的话，覆盖前先做一步）

补丁的 `.rpy` 会被引擎在启动时编译成 `.rpyc`。**旧编译产物不清掉会影响加载**
（表现是「装了新版本但行为没变」，严重时引擎直接报错）。所以覆盖之前先删掉这两个目录下
遗留的 `.rpyc`：

```
<游戏目录>\game\a11y_platform\*.rpyc
<游戏目录>\game\a11y_game\*.rpyc
```

或者干脆一点：**先把 `game\a11y_platform\` 与 `game\a11y_game\` 整个删掉，再把新 zip
解压到游戏目录** —— 最省事，也最不容易漏。`nvdaControllerClient64.dll` 与文档直接覆盖即可。

## 卸载

**删掉这两个目录就是卸载**（效果与从未装过完全一样）：

```
<游戏目录>\game\a11y_platform\
<游戏目录>\game\a11y_game\
```

游戏原有文件一个都没被改过，所以删完就是原样。几件小事说明一下：

- 补丁放进 `<游戏目录>\game\` 的 `nvdaControllerClient64.dll`（NVDA 的第三方客户端库）
  也可以一起删；根目录的 `安装说明.md`、`常见问题.md` 与 `licenses\` 是纯文档，
  留着不影响运行，删掉也不影响。若你的游戏目录里原本就有同名文件，
  用 Steam 的「属性 → 已安装文件 → 验证游戏文件的完整性」即可还原。
- 补丁**不生成、不修改存档，也不碰成就**。
- 唯一会留在玩家偏好里的痕迹：补丁会**关闭引擎的「自语音」开关**
  （打开它反而会让界面播报变成引擎自己凑的文本）。你随时可以在游戏设置里
  自己打开，补丁不与你争抢 —— 只是界面播报会退回引擎那一套。

## 按键

| 键 | 作用 |
|---|---|
| **F5** | 重读上一句（按下先响一声短提示音，再朗读） |
| **F9** | 切换朗读后端：自动 → NVDA → 引擎同款 SAPI → 两者同时 |
| **1–9** | 选项界面：直接选第 N 项（主键盘与小键盘都认） |
| **↑ / ↓** | 在控件间**线性**移动（一个不漏地走遍当前界面） |
| **回车 / 空格** | 确认当前控件 |
| **Esc** | 返回 / 关闭（引擎原生行为） |
| **Ctrl+Shift+I** | 现场快照（把当前界面识别不出的控件写进 `log.txt`，排查用） |

几点说明：

- **重读键不是 `Backspace`。** 本作把 `Backspace` 留给了文本输入，
  上游纪律是「不抢游戏原生占用的键」，所以补丁用的是 **F5**。
- **不要用 `v` 键。** 那是引擎内建的「自语音」开关，在 Windows 上走 SAPI、
  不认识 NVDA。本补丁的朗读**默认已经开着**，不需要你去按它。
- **`←` / `→` 补丁不接管** —— 它们本来就是滑杆调节与视口滚动用的（引擎原生行为），
  补丁只接管上下方向键。
- **F9 切到的档位如果一片安静**：说明那一路在本机不可用。钉死的档位**不会**自动回退
  （这是刻意的 —— 否则你分不清「这路坏了」还是「切过去了」），再按 F9 换下一档即可。
- **`F5` 那声提示音是刻意加的**：盲人玩家分不出「键没送到」和「送到了但读屏没出声」，
  两者听感完全一样。有提示音 + 有朗读 = 正常；有提示音 + 没朗读 = 朗读通路的问题；
  没提示音 = 键没送到。这一条能让反馈一次说清。
- **不需要「导航模式」。** 有些游戏的读屏补丁要先按一个键进入界面导航模式，
  本补丁**不用** —— Ren'Py 引擎自带「焦点」系统，补丁是挂钩它而不是另搭一套，
  方向键、回车、`Esc` 全都保持引擎原生行为，按键就是按键。

## 朗读行为

| 情况 | 念什么 |
|---|---|
| 旁白 / 没有角色名的内容（占全部台词 **43.2%**） | **全文朗读** |
| 有角色名、但该角色**本来就没有配音**（主角等） | **全文朗读**（含角色名） |
| 有角色名、**有配音** | **不念** —— 配音本身就在说明是谁在说；按 **F5** 可以问「现在这一句是谁在说」 |
| 有配音、但你把**配音调成了静音** | **全文朗读**（否则那几句会凭空消失） |

另外几条：

- 说话人未知时（画面上的 `？？？`）读作「未知」。
- 全部界面的图片按钮都登记了朗读文案（覆盖率由工具核对到 **100%**：
  设置两页、存读档、画廊、立绘、音声鉴赏、历史记录、确认弹窗、通知都在内）。
- **永不静默**：万一某个控件没有登记文案，补丁宁可念出一个可核查的标识
  （形如「未命名控件（某图.png，某动作）」），也不保持沉默 ——
  沉默是最难查的故障。**这不是故障噪音，它是探针**：
  把听到的那一串反馈给维护者，正好就是补全文案需要的信息。
- 玩家主动发起的朗读（F5 重读、数字键选选项、方向键逐项）会**打断**上一句；
  自动播报（开屏、菜单逐项）只**排队**，不打断 —— 宁可滞后，不可缺失。

## 已知限制（如实写，不粉饰）

- **立绘页的缩放 / 拖动仍只有鼠标**；
- **画廊的 CG 缩略图只报「第 N 张」** —— 那些图在画面上一个字都没有，
  既没有可读标题、也不能从文件名猜内容，补丁**不编造**；
- 部分**动态生成**的控件（如历史记录里每条右侧的按钮）不在覆盖率工具的扫描范围内，
  靠上面那条「永不静默」的探针兜底；
- **不扩大可达范围**：未解锁的按钮只朗读「尚未解锁」，不会被变成可点；
- **不支持争渡（ZDSR）读屏**，也不计划支持（本机实测判据不成立）；
- NVDA 控制器这条路存在一个**尚未查清**的现象：极少数情况下「只有第一句出声」，
  返回码却是正常的。按 **F9** 切到「两者同时」就能继续用
  （同一句同时走 NVDA 与引擎同款 SAPI，也方便当场分辨是哪一路在响）。

## 怎么反馈

带上三样东西，维护者能直接从日志里看出是「没送到后端」还是「送到了但读屏没出声」：

1. 你**听到的**（不用准确，说个大概就行）；
2. 游戏目录下的两个日志：

   ```
   <游戏目录>\log.txt            每次运行覆盖，含补丁的启动与播报记录
   <游戏目录>\a11y_speech.log    累积追加，含每次朗读的文本与后端返回码
   ```

3. **是在哪个界面、按了什么键**。

> ⚠ **这两个日志可能含剧本原文**（对话朗读记录）。
> 只发给维护者排查用，**不要公开贴出、不要提交进任何仓库**。

按 **Ctrl+Shift+I** 还能让补丁把「当前界面识别不出的控件」写进 `log.txt`：
那份清单就是下一轮要补的文案，格式是 `图片@x,y`，能直接在源码里查到对应的控件。
